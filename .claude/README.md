# Thư mục .claude

```
.claude/
  settings.json     Quyền dùng chung (cho phép pnpm/git đọc, chặn commit/push/npm)
  rules/            Quy tắc theo chủ đề: git.md, architecture.md, data.md
  commands/         Lệnh tắt: /check, /dead-code
  agents/           Subagent: engine-reviewer
```

Cài đặt cá nhân đặt ở `.claude/settings.local.json` (không commit). Quy tắc tổng quát nằm ở `CLAUDE.md` ở gốc dự án.
